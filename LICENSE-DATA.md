# Dataset attribution

I use the **Online Retail** dataset for this project. It was created by Daqing Chen and published by the UCI Machine Learning Repository in 2015.

- Dataset: [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
- DOI: [10.24432/C5BW33](https://doi.org/10.24432/C5BW33)
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The original workbook is not included in this repository. My analysis uses a cleaned subset of positive sales, with additional revenue calculations and customer-level RFM features.
